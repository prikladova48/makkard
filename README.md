# Telegram Mini App MVP: ресурсная карта дня

Это первый тестовый прототип мини-приложения для Telegram.

## Что внутри

- 7 первых карт из колоды.
- Кнопка «Карта дня».
- Кнопка «Вытянуть случайную карту» для тестирования.
- Послание, привязанное к конкретной карте.
- Случайный вопрос из общего списка.
- SVG-заглушки для картинок, которые можно заменить на свои изображения.

## Как заменить картинки

1. Открой папку `assets/cards`.
2. Замени файлы `card-01.svg`, `card-02.svg` и так далее на свои картинки.
3. Можно использовать PNG, JPG или WEBP.
4. Если меняешь расширение файла, открой `data.js` и поменяй путь, например:

`assets/cards/card-01.svg`

на

`assets/cards/card-01.png`

Лучше использовать вертикальный формат 3:4.

## Как изменить тексты карт

Открой `data.js`.

В блоке `window.CARDS` можно менять:

- `title` — название карты.
- `description` — короткое описание.
- `message` — послание к карте.
- `image` — путь к картинке.

В блоке `window.QUESTIONS` можно менять список вопросов.

## Как проверить без Telegram

Открой `index.html` в браузере. Основная механика будет работать.

## Как загрузить для Telegram

Telegram Mini App должен быть доступен по HTTPS-ссылке.

Простые варианты для теста:

1. GitHub Pages.
2. Netlify.
3. Vercel.
4. Любой свой хостинг с HTTPS.

После загрузки сайта нужно взять HTTPS-ссылку на `index.html` или корень сайта и указать её в BotFather.

## Как подключить в BotFather

1. Открой @BotFather в Telegram.
2. Создай бота через `/newbot`, если его ещё нет.
3. Для кнопки в меню используй `/setmenubutton` или путь Bot Settings → Menu Button.
4. Вставь HTTPS-ссылку на приложение.
5. Название кнопки можно сделать: `Открыть колоду`.

Также можно создать полноценное Mini App через настройки BotFather, если Telegram предложит пункт Configure Mini App или `/newapp`.

## Текущий принцип «Карты дня»

Карта дня выбирается по связке:

- ID пользователя Telegram.
- текущая дата.

Поэтому у одного пользователя в течение дня должна выпадать одна и та же карта. Если открыть приложение вне Telegram, создаётся тестовый локальный пользователь в браузере.
