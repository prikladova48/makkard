# Как загрузить этот проект на BotHost

Это версия проекта с Node.js-обёрткой для BotHost. Она отличается от обычной статической версии тем, что у неё есть `server.js` и `package.json`, поэтому BotHost сможет запустить приложение как Node.js-проект.

## Что выбрать на BotHost

При создании проекта выбери:

- Платформа: Telegram.
- Язык: Node.js.
- Bot Token: токен твоего бота из @BotFather.
- Порт: 9256, если BotHost попросит указать порт вручную.
- Start command: `npm start`, если BotHost попросит команду запуска.

## Какие файлы должны быть в проекте

В корне проекта должны лежать:

- `index.html`
- `styles.css`
- `app.js`
- `data.js`
- `server.js`
- `package.json`
- папка `assets`

## Как загрузить

Если BotHost даёт загрузку файлов через веб-интерфейс, загрузи содержимое папки проекта.

Если BotHost просит GitHub-ссылку, создай новый репозиторий на GitHub, загрузи туда эти файлы и вставь ссылку на репозиторий в BotHost.

## После запуска

BotHost должен дать публичную HTTPS-ссылку вида `что-то.bothost.ru`.

Эту ссылку нужно будет вставить в BotFather как ссылку на Mini App или как ссылку для Menu Button.

## В BotFather

Минимальный путь:

1. Открой @BotFather.
2. Выбери своего бота.
3. Настрой кнопку меню через `/setmenubutton`.
4. Название кнопки: `Открыть колоду`.
5. URL: HTTPS-ссылка, которую дал BotHost.

После этого в твоём боте появится кнопка, открывающая мини-приложение.
